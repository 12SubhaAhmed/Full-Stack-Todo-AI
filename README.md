This To-Do App was built as part of Hackathon Phase 2 using modern web development technologies. The frontend is developed with Next.js and React, enabling a component-based architecture and efficient state management. TypeScript is used to ensure type safety and reduce runtime errors. The application implements core CRUD functionality, allowing users to add, edit, delete, and mark tasks as completed. Styling is handled using CSS/Tailwind, ensuring a clean and responsive user interface. Throughout development, emphasis was placed on code structure, reusable components, and proper handling of user interactions to simulate real-world application behavior.
